# Myspoti AI

[Myspoti](https://github.com/kota-zo/myspoti)(kota-zo)에 기능 몇 개를 얹어 GitHub이 **매일 자동으로 확인·빌드·서명·배포**하는 비공식 빌드예요.
앱 안의 업데이트 확인(설정, 그리고 앱을 열 때)이 이 레포의 릴리스를 읽어서, 새 빌드가 있으면 버튼 한 번으로 업데이트돼요.

## 기능

| 기능 | 설명 |
|---|---|
| Gemini 가사 번역 | 직역/중간/의역, 곡별 다시 번역. 키가 없으면 원래 번역기를 써요 |
| AI 발음 | 외국어 가사를 한글 발음으로 표시 (가사 메뉴에서 켜기/끄기) |
| Gemini API 키 | 가사 메뉴에서 입력. 폰의 Android Keystore로 암호화해 저장 |
| 음량 미세조절 | "다음에서 듣기" 창 맨 위에서 1%씩 −/+ (길게 누르면 반복) |
| 한국어 고정 | 폰 언어와 상관없이 한국어로 시작(설정에서 다른 언어를 고르면 그대로 따라요). 원본에 한국어가 없는 화면 문자열 약 1,200개도 채워요 |

앱 이름은 **Myspoti AI**, 앱 ID는 `app.myspoti.ai`라서 원본 앱과 따로 설치돼요.

## 어떻게 돌아가나

- `overlay/` : 새로 쓴 파일들 (Gemini, 음량 처리기, 메뉴 등). 원본 코드는 이 레포에 없어요.
- `patches/apply.py` : 원본 코드에 한두 줄씩 연결하는 스크립트. 위치를 줄 번호가 아니라 **함수 이름·호출**로 찾고, 같은 자리를 찾는 방법을 여러 개 둬요.
- `.github/workflows/release.yml` : 매일 원본의 새 릴리스 확인 → 패치 → 빌드 → 서명 → 릴리스.

## 원본이 바뀌면

| 상황 | 일어나는 일 |
|---|---|
| 평소 | 자동으로 새 빌드가 올라와요. 앱 설정에서 업데이트 확인 → 업데이트 |
| 음량 미세조절만 안 맞음 | 음량만 빼고 새로 빌드해서 올려요. 릴리스 노트에 "음량 없음"이라고 적혀요 |
| 번역·발음·메뉴·한국어 연결이 안 맞음 | 아무것도 올리지 않아요(폰은 기존 버전 유지). 알림도 없어요. Actions 로그를 보고 `patches/apply.py`의 그 자리를 고치면 돼요 |

설치와 설정은 [docs/SETUP.md](docs/SETUP.md), 저작권과 라이선스는 [NOTICE.md](NOTICE.md)를 보세요.
